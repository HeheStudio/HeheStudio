# Hehe Design

Online shop for customisable, made-to-measure shelves: https://hehe.design

Customers design a shelf in a ShapeDiver App Builder configurator and pay through Stripe Checkout.

## Local development

1. Copy `.env.example` to `.env` and fill it in.
2. Run `npx netlify dev` and open the address it shows. `npm run dev` does not run the checkout function.
